# 参考ビューワの解析結果と Lviewer 対応表

Lviewer は、従来使っていた単画面型ビューワ（以下「参考ビューワ」。2012年で更新停止）の操作感を手本にした**新規実装**の画像ビューワです。
参考ビューワのバイナリ・アイコン・ツールバー画像・ヘルプ文章は一切流用していません（配布条件で改変が禁止されているため、本体の改造ではなく別ソフトとして作り直しました）。

## 1. 解析の方法

| 対象 | 方法 | 得られた情報 |
|---|---|---|
| ヘルプ（chm、91 ページ） | 7-Zip で HTML を展開→テキスト化 | 全メニュー項目、キーボード/マウス操作、表示オプション・フィットオプションの挙動、マスク処理の仕様、起動オプション、仕様上の制限 |
| 本体 exe のリソース | 7-Zip で `.rsrc` を展開（逆アセンブルはしていない） | メニュー構成とコマンドID（`MENU`）、**既定キー割り当て表**（`FILE/82`、105 件）、キー名表（`FILE/80`） |
| 設定ファイル（UTF-16LE の INI） | セクション・キー名の読み取り | 設定項目の一覧（`[Wnd]` `[Other]` `[Flag]` `[Dlg]` `[Save]` `[Load]` 等） |
| `spi32008/Spi_api.txt` | 読解 | Susie Plug-in API（32bit DLL 前提） |

### 既定キー割り当て表（`FILE/82`）の形式
`MGCustom` ヘッダ + `Keys` セクション。各レコードは
`コマンドID(u16) / キー数 n(u16) / 修飾キー n バイト / 仮想キーコード n×u16`。
修飾キーは bit2=Shift、bit3=Ctrl、bit4=Alt。Lviewer の既定キーはこの表をそのまま採用しています（`src/CommandList.inc`）。

## 2. TIFF を「最初から」読める理由

参考ビューワ本体は BMP/GIF/JPEG/PNG しか読めず、TIFF は Susie プラグイン（`ifTIFF6.spi` 等、32bit DLL）頼みでした。
Lviewer は **Windows 標準の Windows Imaging Component (WIC)** で画像を読むため、追加 DLL なしで以下を直接扱えます。

- TIFF：マルチページ、無圧縮 / LZW / ZIP(Deflate) / PackBits / JPEG / CCITT G3 / CCITT G4、1・8・16 bit、透明（アルファ）
- JPEG、PNG、GIF（アニメ）、BMP、ICO、JPEG XR
- Microsoft Store のコーデックを入れた PC では WebP・HEIF・各種 RAW も自動で対応（「その他 > 対応形式一覧」で確認可）

画像の情報（`I` キー）には TIFF の圧縮方式・Photometric・解像度(dpi)・ページ数を表示します。
保存は PNG / JPEG / TIFF / BMP / GIF / JPEG XR。TIFF 保存時は圧縮方式（自動 / 無圧縮 / LZW / ZIP / CCITT G4 / PackBits）を選べ、白黒2値画像は自動で CCITT G4 になります。

## 4. 設定ファイル（`Lviewer.ini`）

- 置き場所：`Lviewer.exe` と同じフォルダ（書き込めない場合は `%APPDATA%\Lviewer\`）。`/user=名前` で `user\名前\Lviewer.ini` を使用（参考ビューワの `/user=` と同じ考え方）
- 主なセクション：`[General]`（言語・多重起動）、`[Window]`、`[Background]`、`[View]`、`[List]`、`[Comic]`、`[Slide]`、`[Mouse]`、`[File]`、`[Save]`、`[Edit]`、`[Mask]`、`[MRU]`、`[OtherApp]`、`[Keys]`
- `[Keys]` は既定から変更したコマンドだけを `コマンド名=Ctrl+O,Num0,WheelUp` の形で保存

## 5. 参考ビューワと意図的に変えた点

| 項目 | 参考ビューワ | Lviewer | 理由 |
|---|---|---|---|
| 透明画像 | 読込時に背景色と合成（保存すると透明が失われる） | 透明を保持し、表示時だけ市松模様と合成 | 保存で情報を失わないため |
| 長いパス | 260 文字まで | 260 文字超（`\\?\`）と UNC パスに対応 | ネットワーク共有の深い階層対策 |
| 32/64bit | 32bit | 64bit | 巨大な TIFF（数億画素）をメモリに展開するため |
| 拡大縮小エンジン | 独自エンジン | 面積平均・バイリニア・バイキュービックをマルチスレッドで自作 | 同等の画質と速度を新規実装で確保 |
